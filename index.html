出席確認ツール

共有データにアクセスするには、招待されたアカウントでログインしてください。新規登録は管理者がSupabase側で行います（この画面からは登録できません）。

一度ログインすると、この端末ではログイン状態が保持され、次回からは自動でログインします。

接続先：Supabase（東京リージョン）／ データはログインした人だけが読み書きできます。

接続状態：確認中…

サーバー到達テスト：テスト用ページを開く
開いたページに {"version": …} のような英字の文が表示されれば、サーバーには届いています。なお、キーを付けずに開いたときの「No API key found in request」という表示も、サーバーに届いた証拠で、エラーではありません。

接続中…
